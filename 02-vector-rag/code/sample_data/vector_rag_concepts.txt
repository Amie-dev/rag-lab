Vector RAG Architecture Concepts

1. Embeddings: Dense numerical vectors generated by embedding models (like OpenAI text-embedding-3 or MiniLM) capturing semantic text representations.
2. Distance Metrics: Cosine similarity measures angular orientation, Dot product calculates directional magnitude, and Euclidean distance measures spatial separation in vector space.
3. ANN Indexes: Approximate Nearest Neighbor indexes (such as HNSW graphs and IVF inverted files) accelerate top-K vector search across millions of documents without brute-force exhaustive scanning.
4. Top-K Context Augmentation: The vector store retrieves the top K most relevant text chunks based on semantic similarity score to construct the augmented prompt for the Large Language Model.
